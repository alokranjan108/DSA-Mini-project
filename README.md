## 📌 About the Project

DSA Algorithm Visualizer is an educational web application that helps students understand how different data structures and algorithms work.

Instead of learning algorithms only through theory, users can interact with visual representations and observe how operations are performed step by step.

The main objective is to improve conceptual understanding of DSA through practical demonstrations.

---

## 🎯 Project Objectives

- Understand Data Structures through visualization.
- Demonstrate algorithms step by step.
- Learn sorting and searching techniques.
- Understand different data structure operations.
- Display time and space complexity.
- Provide an interactive learning experience.

---

## ✨ Features

### 1. Sorting Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

### 2. Searching Algorithms
- Linear Search
- Binary Search

### 3. Data Structures
- Stack (Push, Pop, Peek)
- Queue (Enqueue, Dequeue)
- Circular Queue
- Linked List
- Binary Search Tree

### 4. Graph Algorithms
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Dijkstra's Shortest Path Algorithm

### 5. Additional Features
- Interactive visualization.
- Step-by-step algorithm execution.
- Custom input support.
- Time and space complexity information.
- Reset and replay operations.

## ⚙️ Installation and Setup

**Step 1: Clone the repository**

```bash
git clone https://github.com/alokranjan108/DSA-Mini-project.git
```

**Step 2: Open the project folder**

```bash
cd DSA-Mini-project
```

**Step 3: Run the application**

Open `index.html` in your web browser.

Alternatively, use the Live Server extension in Visual Studio Code.
